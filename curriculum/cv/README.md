# Chuvash Curriculum (`curriculum/cv/`)

This directory contains curriculum specifications for Chuvash (`cv`).

## Reference Manuals for Chuvash

When building out or modifying the Chuvash curriculum (e.g., `curriculum/cv/general/A1.json`), contributors should refer to the existing Chuvash reference manuals to maintain consistency with vocabulary and grammar choices:

- **Grammar Manual (`chavash-grammatika/`)**: `Чăваш грамматики` (A0–A1 level grammar manual)
- **Vocabulary Manual (`chavash-leksiki/`)**: `Чăваш лексики` (A0–A1 level vocabulary manual)
- **Unified Manual Hub**: `manuals/chavash-a0-a1.html`
