# COSYlanguages Documentation Index

Welcome to the documentation directory for **COSYlanguages**.

## Directory Structure

- **`CONTENT_ARCHITECTURE.md`**: The primary content specification and taxonomy guide for courses, practice modes, and vocabulary datasets.
- **`archive/`**: Contains historical documentation, obsolete audit logs, and legacy reports (`DUPLICATION_AUDIT.md`, `CANON_SOURCE_OF_TRUTH.md`, `reports/`, `wordlists/`). Note that material inside `archive/` is retained strictly for historical context and may be out of date.

For active operational guidelines, see the main repository [README.md](../README.md).
