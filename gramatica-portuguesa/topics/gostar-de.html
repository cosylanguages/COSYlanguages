Gostar de

A construção gostar de + substantivo / infinitivo e contrações (do, da, dos, das)

PronomeGostarPreposição / ContraçãoComplemento
eugostode / do / damúsica / do café / da praia
tugostasde / dos / dasestudar / dos livros
você / ele / elagostade / do / daviajar / da cidade
nósgostamosde / dos / dasesportes / das férias
vocês / eles / elasgostamde / do / dacinema / do verão

👀 Atenção

O verbo gostar exige sempre a preposição de. Diante de artigos definidos, contrai-se: de + o = do, de + a = da, de + os = dos, de + as = das. Antes de verbos no infinitivo, usa-se apenas de (gosto de ler).

💡 Dica mnemônica

Gostar DE + Infinitivo | Gostar DO/DA + Substantivo.

⚠️ Erros comuns
❌ Eu gosto o café
clique para revelar a forma correta
✅ Eu gosto do café (gosto de + o café)

🎯 Autoavaliação

Quiz

Como se diz «She likes the beach (a praia)»?
A preposição «de» junta-se ao artigo «a» formando a contração «da»: «Ela gosta da praia».
