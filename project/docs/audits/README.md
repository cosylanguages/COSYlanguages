# Audits & Reports Directory (`project/docs/audits/`)

This directory consolidates all audit, report, analysis, and brainstorm documentation for the **COSYlanguages** codebase.

## Directory Structure

* **`active/`**: Audit reports, dataset analyses, and strategy documents that are currently active, relevant, or operational.
* **`archive/`**: Superseded, historical, or completed audit logs, phase roadmaps, and legacy session/game brainstorms.
