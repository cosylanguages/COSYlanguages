Part 3 &middot; Describing Things

Some vs Any

Choosing the right word by sentence type

📱 Vocabulary theme for practice: Shopping &amp; quantities
What kind of sentence is it?
statement, offer, request
affirmative
I have some apples.
not / don't / doesn't
negative
I don't have any apples.
asking
question
Do you have any apples?
UseExample
some · affirmative sentences, offers & requestsI have some apples. Would you like some tea?
any · negative sentencesI don't have any apples.
any · questionsDo you have any apples?

💡 Some in questions, too

When you're offering something or expecting 'yes', some can appear in a question: Would you like some coffee? (a genuine offer, not a plain question).
