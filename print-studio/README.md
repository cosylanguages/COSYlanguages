# COSY Print Studio Staging Area

This directory (`print-studio/`) serves as the consolidated staging area for all pedagogical print tools, flashcard generators, pocket zines, box models, and boardgame builders in the COSYlanguages ecosystem.

## Migration Notice
Per **DUP-003** in `docs/ecosystem-audit.md` and `docs/ECOSYSTEM_ARCHITECTURE.md`, this entire directory is isolated and staged for migration into a dedicated standalone repository: **COSYstudio** (`https://github.com/cosylanguages/COSYstudio`).

## Consolidated Sub-Applications & Tools
- `print-boardgame.html`: Print-and-play conversational board game generator.
- `print-box.html`: Leitner flashcard box 3D papercraft template builder.
- `print-cards.html`: Printable Leitner flashcard front/back grid generator.
- `print-grammar.html`: Printable grammar reference sheets and cheat sheets.
- `print-zine.html`: 8-page A4 single-sheet foldable pocket booklet compiler.
- `package.json`: Workspace package configuration (`@cosy/print-studio`).
